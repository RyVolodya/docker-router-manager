# Add these files to the DRM repository

Copy `README.md`, `.gitignore`, and the complete `docs/` directory to the root
of your Docker Router Manager repository.

The README currently uses:

- `docs/images/drm-logo.svg`
- `docs/images/dashboard.png`
- `docs/images/topology.png`
- `docs/images/firewall.png`
- `docs/images/routing.png`
- `docs/images/wireguard.png`

Before publishing, replace `YOUR_USERNAME` in the clone command with your
GitHub username/repository URL.

If you selected GPL-3.0 when creating the GitHub repository, keep GitHub's
generated `LICENSE` file in the repository root.
